# Scientific Figure Reference Library

临床研究与单细胞/空间组学科研绘图示例库，主要供 **Codex 在绘制论文图片时检索、学习和复用设计规范**。

## 目标

- 为临床研究、转化医学、单细胞和空间组学图片建立可检索的参考库。
- 让 Codex 在开始绘图前先寻找相似示例，学习布局、配色、图例、统计注释和视觉层级。
- 积累可复用的科研绘图规范与模板，减少重复沟通并保持论文图片风格一致。
- 参考的是设计和表达方式，不是示例中的数据、统计结果或研究结论。

## 目录结构

```text
clinical/       临床研究图：队列流程、基线特征、生存、疗效、森林图、生物标志物、预测模型、纵向研究和图形摘要
single_cell/    单细胞/空间组学图：QC、整合、UMAP、注释、组成、差异表达、富集、拟时序、通讯、TCR/BCR、调控模块和空间组学
shared/         通用规范：配色、组合布局、字体、图例、统计标注、投稿导出
templates/      可复用绘图代码模板（R/ggplot2、Survival、Seurat、Python/Scanpy）
sources/        示例索引、文献来源和版权/许可记录
AGENTS.md       Codex 使用本仓库的工作规则
```

每个子目录使用编号前缀，便于排序和稳定检索。具体分类见目录名。

## Codex 使用流程

1. 先阅读本文件和根目录 `AGENTS.md`。
2. 根据目标图形检索 `clinical/`、`single_cell/` 和 `shared/` 中的示例。
3. 实际查看候选图片，并核对 `sources/figure_index.csv` 中的来源；不要猜测图片出处。
4. 借鉴图形结构、配色、标注和布局，用当前项目数据重新绘制。
5. 交付时尽可能同时提供可复现代码、PDF 矢量图和 300 dpi PNG，并检查图片是否能正常打开。
6. 没有找到合适示例时应明确说明，不要声称已参考不存在的图片。

## 如何添加示例

- 建议文件名：`YYYYMMDD_domain_figure-type_short-description_v01.ext`。
- 将图片放入最匹配的分类目录，不要把未分类图片堆放在根目录。
- 在 `sources/figure_index.csv` 记录标题、分类、来源、DOI/URL、图号、可借鉴之处和许可信息。
- 对重要示例，可在图片旁添加同名 Markdown 说明，写明用途、软件、关键参数和注意事项。
- 优先使用自己制作、明确开放许可或已获授权的图片。公开可见不等于可以自由转载。
- 不上传患者姓名、住院号、可识别影像、原始临床记录、凭据或未经授权的未发表数据。

## 默认绘图规范

当前任务或项目中的明确要求优先于本仓库默认值。

- 投稿图适用时优先导出 PDF + PNG；PNG 使用 300 dpi。
- 同一组图片尽量统一画布尺寸、字体层级、线宽、面板间距和图例风格。
- 对密集散点，可只栅格化数据密集图层，尽量保留文字、坐标轴和标签的清晰度。
- 准确呈现分母、样本量、单位、效应量、置信区间、统计检验和 P 值；不能为视觉效果改变统计含义。
- 默认二分类配色（仅当项目没有指定配色时）：Positive `#B2182B`、Negative `#999999`、Missing `#D9D9D9`。根据变量语义和整套图形调整，不要强行套用。
- 保存代码和关键参数以便复现；不要将真实患者信息打包进通用模板。
