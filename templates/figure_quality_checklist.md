# Scientific Figure Quality Checklist

## Scientific validity
- [ ] Figure answers the intended scientific question.
- [ ] Labels, units, group definitions, sample sizes, denominators, and time points are verified.
- [ ] Statistical tests and annotations match the actual analysis.
- [ ] Effect sizes and uncertainty are reported when appropriate.
- [ ] No claim exceeds the evidence.

## Design and readability
- [ ] Clear visual hierarchy and concise message.
- [ ] Labels, axes, legends, and panel letters readable at final size.
- [ ] Panels aligned; typography, spacing, and line widths consistent.
- [ ] Colors are semantically appropriate and distinguishable.
- [ ] No clipped, overlapping, or obscured labels.
- [ ] Axes and scales do not misrepresent results.

## Reproducibility and delivery
- [ ] Plotting code and key parameters saved.
- [ ] PDF and 300 dpi PNG exported when appropriate.
- [ ] Dimensions consistent across related figures.
- [ ] Output files open and render correctly.
- [ ] Source and reuse permissions recorded.
