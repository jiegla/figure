# Source, Attribution, and Copyright Notes

Record the following for each reference image where applicable:

- Figure file path, title, domain, and figure type
- Source type (self-created, article, supplement, preprint, public database, etc.)
- Full citation and stable DOI/URL
- Figure/panel number and software/package
- What is useful about the design (layout, colors, legend, annotations, visual hierarchy)
- Known limitations and license/permission status (write `unknown` if not verified)
- Date added

Rules:
- A publicly viewable image is not automatically free to redistribute.
- Prefer self-created images, explicitly open-licensed materials, or assets with permission.
- Keep attribution and license information in `figure_index.csv` or an adjacent Markdown note.
- Do not commit entire papers, identifiable patient information, credentials, or confidential data without authorization.
- If permission is uncertain, do not imply the image is approved for reuse.
